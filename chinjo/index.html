陳情・請願

議会に直接働きかける手段が陳情・請願です。行政ではなく議会を動かすことで、条例制定・廃止・予算修正を求めることができます。手続きと高知減税会の提出記録を掲載しています。

陳情と請願の違い

陳情（ちんじょう）

  • 議会に対する意見・要望の申し入れ
  • 議員の紹介は不要
  • 受理されると委員会で審査される
  • 憲法上の権利ではなく、議会の裁量で扱われる
  • 採択・不採択・継続審査のいずれかとなる

請願（せいがん）

  • 憲法第16条に定める基本的権利
  • 議員1名以上の紹介が必要
  • 受理されると本会議・委員会で審査される
  • 採択された場合、行政への意見書提出が可能になる
  • より拘束力のある手続き

どちらを使うべきか

紹介議員が確保できる場合は請願、できない場合は陳情が現実的です。高知減税会は選挙前後に紹介議員の確保を試み、請願提出を優先しています。陳情も議事録に残り、次の選挙での論点になります。

陳情の提出手順

  1. 対象議会（市議会・県議会）の議会事務局に「陳情書」の提出先・書式を確認する
  2. 陳情書を作成する（表題・陳情の趣旨・陳情の理由・提出者氏名・住所・日付）
  3. 議会事務局に持参または郵送・メールで提出する（受付締切を確認）
  4. 定例会・臨時会の該当委員会で審査される（傍聴可能）
  5. 採否の結果を議事録・議会ウェブサイトで確認する

請願の提出手順

  1. 紹介議員（1名以上）に趣旨を説明し、署名・押印（または記名）を得る
  2. 請願書を作成する（表題・請願の趣旨・請願事項・提出者氏名・住所・日付・紹介議員氏名）
  3. 議会事務局に提出する（受付締切は定例会開会の数日前が多い）
  4. 本会議で所管委員会に付託される
  5. 委員会審査 → 本会議採決という流れで処理される
  6. 採択された場合、内閣・関係行政庁への意見書提出が可能になる

効果的な書き方

陳情書・請願書の構成

  • 表題 — 「○○に関する陳情書」のように1行で内容がわかるもの
  • 趣旨 — 求めることを3行以内で簡潔に。「○○を実施すること」と命令形で書く
  • 理由 — 根拠となる数字・事実・条文を示す。感情的表現は避ける
  • 署名連記 — 多数の署名があると議会は無視しにくくなる

注意点

  • 特定の個人・団体への攻撃的内容は受理されない場合があります
  • 否決・不採択になった内容を同一会期中に再提出することはできません
  • 議会の会期外に提出しても、次の会期まで審査されません。定例会の日程を確認してください
